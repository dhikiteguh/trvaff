Tidak bisa diseret? Pasang manual

Buat bookmark baru, isi nama "Ambil Data Hotel", lalu tempel kode ini di kolom URL:

  1. Tempel link trv.lk di slot Hotel 1, lalu buka link itu di tab baru (klik "Buka").
  2. Di halaman hotel Traveloka, klik bookmark 📌 Ambil Data Hotel. Data tersalin otomatis.
  3. Kembali ke sini, tempel (Ctrl+V / ⌘+V) di kolom Data hotel. Ulangi untuk Hotel 2, lalu klik Salin kode.
